Download

Download NeoSCAD

NeoSCAD 0.1.0 is out for macOS, Linux and Windows. Every file is on the GitHub release, with its sha256; this page lists them by platform, with the package managers and what is still to come.

Install the command-line tool with Homebrew, on macOS or Linux:

brew install neoscad/tap/neoscad

or with the install script (macOS and Linux; it installs to ~/.cargo/bin):

curl --proto '=https' --tlsv1.2 -LsSf https://github.com/neoscad/neoscad/releases/download/v0.1.0/neoscad-cli-installer.sh | sh

or on Windows, in PowerShell:

powershell -ExecutionPolicy Bypass -c "irm https://github.com/neoscad/neoscad/releases/download/v0.1.0/neoscad-cli-installer.ps1 | iex"

neoscad, the command-line tool, includes the language server (neoscad lsp), the MCP server (neoscad mcp) and neoscad serve on every platform. The app is macOS-only. Fonts and MCAD are built in; BOSL2 and your other libraries load from OPENSCADPATH, as in OpenSCAD.

macOS Available

macOS 15 or later. The app is universal (Apple silicon and Intel), signed with a Developer ID and notarized, so Gatekeeper accepts it. The command-line tool comes as one archive per architecture.

  • NeoSCAD for macOS (.dmg) The app: editor, 3D view, console, check and measure panels, a customizer (partial) and Quick Look previews. sha256. Or brew install --cask neoscad/tap/neoscad-app. The command-line tool is a separate download below. Available
  • Command-line tool, Apple silicon (.tar.xz) A single neoscad binary. sha256 Available
  • Command-line tool, Intel x86_64 (.tar.xz) The same, for Intel Macs. sha256 Available

Linux Available

Command-line tool only. glibc 2.28 or later. PNG export and snapshot need a Vulkan driver; Mesa's works without a GPU.

  • x86_64 (.tar.xz) A single binary; the install script above fetches it. sha256 Available
  • aarch64 (.tar.xz) Built natively on ARM. sha256 Available
  • Debian and Ubuntu (.deb): amd64 (sha256), arm64 (sha256) With the man page and bash, zsh and fish completions. sudo apt install ./neoscad_0.1.0-1_amd64.deb Available
  • Fedora and RHEL (.rpm): x86_64 (sha256), aarch64 (sha256) The same contents. A signed apt/rpm repository comes later. Available

Windows Available

Command-line tool only, as a portable zip or an MSI, for x86_64 and ARM64. neoscad serve listens on a named pipe.

The Windows builds are not code-signed. Opening a downloaded .exe or .msi shows SmartScreen's “Windows protected your PC”: choose More info, then Run anyway. The PowerShell install script avoids the prompt. To check a file came from NeoSCAD's own build, compare its sha256, or run gh attestation verify <file> -R neoscad/neoscad.

  • x86_64 (.zip) Portable; the PowerShell install script above fetches it. sha256 Available
  • ARM64 (.zip) Built natively on Windows on ARM. sha256 Available
  • Installer (.msi): x86_64 (sha256), ARM64 (sha256) Adds neoscad to your PATH. Unsigned (see above). Available

Package managers

Commands that don't work yet are struck through.

  • Homebrew (macOS and Linux) brew install neoscad/tap/neoscad for the command-line tool; brew install --cask neoscad/tap/neoscad-app for the macOS app. Available
  • Scoop (Windows) scoop bucket add neoscad https://github.com/neoscad/scoop-bucket, then scoop install neoscad. Available
  • Docker (ghcr.io) docker pull ghcr.io/neoscad/neoscad (tags 0.1.0 and latest, amd64 and arm64): Debian slim with Mesa's software renderers, so PNG export works headless. Run it in your model's directory: docker run --rm -v "$PWD:/work" ghcr.io/neoscad/neoscad model.scad -o model.png Available
  • Nix (flake) nix run github:neoscad/neoscad -- model.scad -o model.stl Available
  • winget winget install NeoSCAD.NeoSCAD once the manifest is merged; it is in review. Pending
  • nixpkgs A submission is prepared; use the flake above meanwhile. Pending
  • AUR (neoscad-bin) Waiting for AUR registration, which is closed for now. Meanwhile the release's PKGBUILD builds with makepkg -si. Pending
  • cargo binstall cargo binstall neoscad needs the crate on crates.io first (below). Planned
  • cargo install from crates.io Blocked until NeoSCAD's patched geometry dependencies are published. Planned

Source Available

GPL-2.0-or-later. Builds with Rust 1.98.

  • Source tarball The release's source. sha256 Available
  • Vendored source tarball Includes every Rust dependency (cargo vendor), for offline builds. Available

Nightly builds Planned

Builds of the latest commit, for testing. They aren't scheduled yet; releases are tagged and built by CI.

In the browser Available

neoscad.org/try runs NeoSCAD compiled to WebAssembly: an editor with examples, rendering in your browser with WebGPU, or WebGL 2 where WebGPU isn't available. Nothing is uploaded.

Compared with OpenSCAD's downloads

OpenSCAD's downloads reach many more places today: installers and the GUI on every desktop platform, AppImage, Snap, Flatpak, the Linux distributions, the BSDs, Docker Hub and a WebAssembly build. If you need the OpenSCAD GUI on Linux or Windows, use OpenSCAD.

A few differences in what NeoSCAD ships:

  • Windows on ARM: a native ARM64 build, as a zip and an MSI. OpenSCAD's nightly for Windows is x86_64 only.
  • Linux on ARM: a native aarch64 build with each release. OpenSCAD's aarch64 AppImage nightly hasn't been updated since 2023.09.
  • One binary: fonts and MCAD are compiled in, so the command-line tool needs nothing else installed.

OpenSCAD's channels were checked on 28 September 2026.
