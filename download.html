Download NeoSCAD

Nothing is published yet. This page shows what will ship and in what order, so you know what to expect.

No download works yet. Entries marked Available soon are built for the first release; Planned ones come after it. Their links are placeholders.

neoscad, the command-line tool, includes the language server (neoscad lsp), the MCP server (neoscad mcp) and neoscad serve on every platform. The app is macOS-only for now. Fonts and MCAD are built in; BOSL2 and your other libraries load from OPENSCADPATH, as in OpenSCAD.

macOS Available soon

Apple silicon (arm64), macOS 15 or later. The release will be signed with a Developer ID and notarized, so Gatekeeper accepts it.

  • NeoSCAD for macOS (.dmg) The app: editor, 3D view, console, check and measure panels, a customizer (partial) and Quick Look previews. Available soon
  • Command-line tool, arm64 (.tar.gz) A single neoscad binary, with sha256. Available soon
  • Command-line tool, Intel x86_64 or universal Needs a CI build; the app stays arm64 at first. Planned

Linux Available soon

Command-line tool only. glibc 2.28 or later. PNG export and snapshot need a Vulkan driver; Mesa's works without a GPU.

  • x86_64 (.tar.gz) A single binary, with sha256 and an install script. Available soon
  • aarch64 (.tar.gz) Built natively on ARM. Available soon
  • Static musl build Portable, but without PNG export. Planned

Windows Available soon

Command-line tool only, as a portable zip. neoscad serve works over stdio; socket mode is Unix-only for now.

  • x86_64 (.zip) With sha256 and a PowerShell install script. Available soon
  • ARM64 (.zip) Built natively on Windows on ARM. Available soon
  • Installer (.msi) Adds neoscad to your PATH; needs code signing first. Planned

Package managers

Commands are shown struck through until they work. Names aren't final.

  • Homebrew tap (macOS and Linux) brew install neoscad/tap/neoscad for the command-line tool; a cask for the app follows notarization. Available soon
  • cargo binstall cargo binstall neoscad fetches the prebuilt binary from the release. Available soon
  • .deb and .rpm packages Attached to each release, for x86_64 and aarch64. A signed apt/rpm repository comes later. Available soon
  • AUR (neoscad-bin) After the first public release. Planned
  • Nix A flake first, then nixpkgs. Planned
  • winget and Scoop Manifests for the portable zip; winget wants signed binaries. Planned
  • Docker (ghcr.io) A small Debian image with Mesa's Vulkan driver, so PNG export works headless. Planned
  • cargo install from crates.io Blocked until NeoSCAD's patched geometry dependencies are published. Planned

Source Available soon

GPL-2.0-or-later. Builds with Rust 1.98.

  • Source tarball Each release's source, with sha256. Available soon
  • Vendored source tarball Includes every Rust dependency (cargo vendor), for offline builds. Available soon
  • Git repository github.com/neoscad/neoscad: the full history. Available

Nightly builds Planned

Builds of the latest commit, for testing. They aren't scheduled yet: the first step is tagged releases from CI.

In the browser In progress

NeoSCAD's library crates already build for WebAssembly. An in-browser editor with examples is being built, and will live at neoscad.org/try.

Compared with OpenSCAD's downloads

OpenSCAD's downloads reach many more places today: installers and the GUI on every desktop platform, AppImage, Snap, Flatpak, the Linux distributions, the BSDs, Docker Hub and a WebAssembly build. If you need the OpenSCAD GUI on Linux or Windows, use OpenSCAD.

A few differences in NeoSCAD's plan:

  • Windows on ARM: NeoSCAD plans a native ARM64 build. OpenSCAD's nightly for Windows is x86_64 only.
  • Linux on ARM: a native aarch64 build with each release. OpenSCAD's aarch64 AppImage nightly hasn't been updated since 2023.09.
  • One binary: fonts and MCAD are compiled in, so the command-line tool needs nothing else installed.

OpenSCAD's channels were checked on 28 September 2026.
